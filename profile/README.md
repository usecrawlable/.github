# Crawlable

Crawlable audits how modern AI search engines, answer engines, and retrieval bots parse raw-HTML web architecture, token constraints, and crawler directives.

### Resources & Tooling
- 🌐 **Diagnostic Engine:** [usecrawlable.com](https://usecrawlable.com) — Run a free multi-page visibility scan on your domain.
- 📖 **Open Standards:** Check out our [AI Search & Retrieval Crawler Directory](https://github.com/usecrawlable/ai-crawler-directory) for verified crawler user-agents and robots.txt configurations.

### What We Test
- Raw-HTML extraction and token-budget degradation
- Retrieval bot access rules (`OAI-SearchBot`, `Claude-SearchBot`, `PerplexityBot`)
- Structured indexing (`llms.txt`, `sitemap.xml`, Schema JSON-LD)
