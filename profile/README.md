A repository named exactly **`.github`** serves a special purpose on GitHub, depending on where it is created:

1. **Organization-wide defaults:** If you are building under a GitHub Organization, a public repository named `.github` acts as the central hub for organization-level community health files, issue/PR templates, and default workflows that apply across all repositories in that org.
2. **Profile / Global automation:** In an organization context, it keeps governance, shared Actions, and documentation cleanly separated from your main application codebase (`ai-crawler-directory`).

### How to set it up:
* **Repository name:** `.github` (make sure to include the leading dot).
* **Visibility:** **Public** (GitHub requires it to be public to serve as the default community profile/templates for organizations, or to display an org profile `README.md`).
* **Initialize with:** A `README.md` file.

Once created, you can use it to store shared workflows (`.github/workflows/`), issue templates, or a profile README for your organization.
